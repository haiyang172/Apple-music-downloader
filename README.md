# 影音下载台

Windows 桌面影音浏览、下载和转码工具，从 amdl 升级而来。Apple Music、B 站、QQ 音乐、网易云音乐和 YouTube 使用同一个下载队列和 FFmpeg。

## 使用

1. 运行 `MediaDownloadDesk-Setup.exe`，或双击便携目录里的 `MediaDownloadDesk.exe`。标准安装包已包含运行时、下载引擎、FFmpeg 和登录组件，并支持从 amdl 覆盖升级。
2. 从左侧选择平台。在「Apple Music」搜索歌曲、艺人、专辑或歌单，或浏览当前地区的热门内容。搜索、热门、资料库和曲目列表会在接近底部时自动加载下一页，直到平台返回最后一页。双击歌曲可试听可用的短片段，双击专辑或歌单可展开曲目。点击列表表头可排序，整张歌单或专辑会按原始顺序拆成逐曲任务。
3. 从平台页头或左下角进入各自的账户页。Apple Music 可填写 Apple 账号和密码，双重认证会弹出验证码窗口。密码保持遮挡并留在表单里。Wrapper Lite 会在当前 Windows 用户目录中保存会话，下次启动时可恢复。
4. 在「下载队列」选择音质和保存目录，再点「开始 / 继续」。筛选某个平台可直接设置对应音质；「全部来源」可展开「来源设置」。也可以在这里添加 Apple Music 单曲、专辑或歌单链接。保存目录可选本地或外接磁盘。若填写分类，文件直接放在这一级分类内。
5. 在「设置」选择保留原音轨，或用 FFmpeg 转换成 FLAC、MP3、AAC、WAV、Opus。MP3 提供 128、192、256 和 320 kbps。

在 Apple Music 页头点「资料库」即可浏览个人歌曲、专辑和歌单。首次点「连接资料库」会打开应用内的 Apple 官方网页，在网页完成登录后，应用会验证资料库授权、加密保存会话并自动显示资料库。网页会话由应用自己的浏览器目录保存，下次可直接恢复。也可展开「使用已有会话令牌」连接已有 Music User Token。个人上传曲目需要对应的 Apple Music 目录版本才能加入下载队列。

首次打开列表时会分批显示并保存完整的本地快照。下次先显示缓存，歌曲可立即排序或选择，Apple Music 在后台同步，成功后应用新增、修改和删除。同步失败时保留已有快照，点「刷新」可重试。在应用中退出 Apple Music 会同时清除应用内网页的登录状态。

Apple Music 封面按窗口所在显示器的缩放比例取图。移到不同缩放比例的显示器时，可见封面会重新加载，列表保留滚动位置和选中项。

下载任务、结果和首次开始时选择的保存设置都保存在本机。重开程序后，点「开始 / 继续」处理剩余任务。已经完成的歌曲保留完成状态，Apple Music 中断的单曲从曲目开头重试。双击队列里的任务可查看保存路径和失败原因。要更换旧任务的目录或格式，选好新设置后右键任务，点「按当前设置重新排队」。

旧版本队列需要升级时，应用会先生成完整的 SQLite 副本，再修改记录结构。副本包含已提交的下载记录、状态和输出设置，保存在 `%LOCALAPPDATA%\amdl\data\backups`，可在「组件 → 队列备份」打开。备份失败时停止升级；新建队列和无需升级的再次启动不会生成重复副本。

应用启动后会在后台查询 GitHub 正式版。「设置」中可以手动检查。发现新版时，点「查看新版」在浏览器打开发布页。

双击已保存的音频任务可查看文件的编码、码率、采样率和声道。原始音轨可读取时，详情会同时列出源音频与输出音频的参数。

可把手机复制的完整分享文案粘贴到对应平台页面。下载队列的「添加链接」也支持一次粘贴多个平台的链接。

要制作车机歌单，在下载队列多选已完成的音频任务，右键选择「导出播放列表」。将 M3U8 保存在音乐文件所在的硬盘或 U 盘，并保持歌曲与歌单的相对位置。

## B 站视频

在左侧「B 站」粘贴视频链接、短链、BV 或 av 号，也可粘贴 UP 主合集、系列或公开收藏夹链接。点「查看分 P」可展开单条视频。直接从合集列表入队时，每条视频默认选择第一个分 P。队列支持 MP4、M4A、MP3 和平台实际返回的原始 FLAC。选择音频格式后，列表显示识别出的歌名、歌手和预计分类。保存音频时，会清理书名号和「纯享版」等修饰，把识别结果用于文件名和歌曲标签。启用「自动分类」后，会按明确的标题标记分到 Persona 系列、音游、游戏原声、粤语或老歌。标记不足时沿用音乐或 B 站分区。所有分类都只建一层，手动指定的分类优先。

选中一个分 P 点「下载预览」，可先检查平台当前提供的音轨、视频规格和源文件大小，并确认歌名、歌手及一级分类。音频可保留原始 AAC/FLAC，或在本条任务中转换为 MP3、AAC/M4A、FLAC、WAV、Opus；MP3 可选码率。视频保持 MP4。弹幕、字幕、封面和作品资料也会随任务保存选择。预览不传输媒体，服务器没有返回大小时会显示未知；下载后仍校验实际文件。普通下载入口继续使用原格式预设。

进入 B 站账户页后可用哔哩哔哩 App 扫码，Windows 会加密保存会话。可用音轨和画质取决于 B 站实际返回，普通公开作品也支持游客下载。可勾选保存公开弹幕（ASS）和当前会话能读取的人工字幕（SRT）。中断后重新打开程序，点「开始 / 继续」。服务器验证原媒体仍一致时，自动从已确认的进度续传。源文件更新或服务器未提供可验证进度时，该分 P 从头开始，已完成的分 P 会跳过。

登录确认后，可在 B 站页打开「我的收藏夹」，查看当前账号的收藏夹和已收藏的合集。打开收藏夹后可展开视频的分 P，也可按列表顺序把各视频的 P1 加入队列。已完整读取的列表按账号缓存在本机，下次可先浏览再后台同步。

勾选「封面与资料」后，应用会在媒体文件旁保存公开封面和 JSON 作品资料。资料包括原始标题、分 P、歌手和投稿者。

音频识别有误时，右键曲目选择「编辑歌名和歌手」。标题中歌名和歌手的顺序颠倒时，可以点「互换」。加入队列后，应用会保存这次修正。

## QQ 音乐、网易云音乐、YouTube 和抖音

在「QQ 音乐」或「网易云音乐」输入歌名即可搜索，向下滚动会继续加载结果。也可粘贴公开单曲、歌单或官方短链接，查看曲目、打开原页面或导出 CSV。网易云会沿歌单原顺序读取平台返回的全部曲目，完整公开 MP3 可直接下载或加入队列。

「QQ 音乐」和「网易云音乐」各有账户页，用对应手机应用扫码。登录后自动读取当前账号的歌单。打开歌单可选曲、下载或加入统一队列。下载平台给当前会话返回的完整音轨，具体曲目和音质依照账号权限。登录会话由当前 Windows 用户加密保存。

在「我的歌单」可多选歌单后点「所选入队」或「下载所选」。应用会按各歌单原顺序展开为逐曲任务，同名的私密歌单也会分别保存任务分组。

确认当前登录后，QQ 音乐和网易云会先显示本机保存的完整歌单和曲目，再在后台同步。同步期间可以继续打开歌单、排序和入队。网络失败或平台只返回部分内容时保留上次完整列表。退出或切换账号会立即隐藏当前账号的私有列表。

在下载队列可分别选择 QQ 音乐、网易云的来源音质。QQ 音乐提供自动、MP3 128/320 kbps 和 FLAC；网易云提供自动、标准、较高、极高、无损和 Hi-Res。自动模式使用平台允许的最佳可用完整音轨，指定音质不满足时会说明原因。任务详情会显示文件实际编码和码率。

在 QQ 音乐或网易云曲目列表选中一首歌，点「下载预览」，可检查平台当前提供的音轨规格、源文件大小、保存格式与预计路径，并选择格式后入队或下载。检查只读取元数据，不下载歌曲；公开网易云音轨使用文件头信息，未知码率会保留为待下载校验。平台规格与文件实际编码分别显示，下载后仍会完整校验。预览确认的设置跟随任务保存，改变格式会保留原任务和文件记录。

Apple Music、QQ 音乐和网易云共用保存格式设置，可保留原音轨，或转为 MP3、AAC/M4A、FLAC、WAV、Opus；MP3 可选 128、192、256、320 kbps。来源音质与保存格式会随任务保存，重启或重试时沿用入队时的选择。旧任务继续使用原先的来源音质。

勾选「QQ 音乐与网易云 · 封面和歌词」，可将歌名、歌手、平台提供的封面及歌词写入保存的音频标签，并在歌曲旁保存封面及 LRC 歌词。保留原音轨时不重新编码，转换格式后也会写入对应格式的标签。

「YouTube」可用关键词搜索视频，也可粘贴视频、Shorts 或公开播放列表链接。搜索和播放列表每次读取 50 个位置，接近列表底部时自动继续，直到平台返回结束；不再固定截断为 500 项。可选择 MP4 视频、M4A 音轨或 MP3。搜索只下载所选视频；播放列表未选项目时显示「下载全部」或「全部入队」，后台读取完整列表后再一次加入队列。可点「停止」取消读取，未读完整的列表不会被当作整张列表入队。播放列表重复的视频保留原位置。

「抖音」支持通过默认浏览器打开视频、图文和短链。在抖音保存作品后，可点「导入已保存文件」进行转码或提取音频。YouTube 和抖音的账户页各自打开官方网页，网页登录在浏览器内完成。

## 本地转码

把一个或多个本地影音文件拖到应用窗口，在鼠标旁选格式即可开始。也可以在「本地转码」先添加文件，再调整保存位置或格式。选项按所选文件类型提供，支持批量转换常见音频与视频，也能从视频提取音轨。转码使用随包 FFmpeg，默认保存到原文件旁边，可改为其他目录。原文件会保留。下载队列中的已保存文件可以右键送到「本地转码」。交互参考 [Filee](https://github.com/KnifeLemon/Filee)。

保留原音轨时只重新封装。FLAC 和 WAV 保留解码出的声道和采样精度。MP3、AAC 和 Opus 会把多声道音源混成立体声。有损源转换为 FLAC 后仍保留原有音质。应用根据曲目时长和实际编码检查每个下载文件，并检查输出可完整解码。重复内容会被识别，同名的不同文件会使用后缀保存。

## 组件

安装包带有 Python/Tk、apmyx 下载后端、FFmpeg、音频工具和 YouTube 下载组件，并附带 Microsoft WebView2 的离线安装组件。Windows 缺少网页运行环境时，安装器会准备它。登录服务使用 [Wrapper Lite](https://github.com/itouakirai/wrapper)，由应用按需启动。服务只监听本机回环接口。首次启动会校验并解压随安装包提供的官方组件，源码运行时也可从固定的官方发行版获取。音质档位受账户和歌曲实际供应影响。

账户页的「高级设置」可连接 Apple Music 网页会话。兼容模式的 ALAC 和 Atmos 可以使用已有的 `u22-amdl` 或在「组件」指定兼容服务。标准账号登录使用安装包自带的 Wrapper Lite。

## 本地构建

支持 Windows 10 2004 或更新版本，x64。源码可在装有 apmyx、Python 3.10+、Tk、PyYAML、Mutagen 及所需音频工具的机器运行。

```powershell
python -m pip install -r requirements.txt
python Studio.py
```

在原 AMDL 离线包中也可以用 `Run.cmd` 启动。需要构建安装包时，在 PowerShell 中运行下面的脚本。

```powershell
.\installer\Build.ps1
```

构建脚本会整理便携版和安装包，并校验 [Wrapper Lite v3.0.4](https://github.com/itouakirai/wrapper/releases/tag/v3.0.4) 后随包提供。也可用 `-WrapperLiteArchive` 指定本机已有的官方 ZIP。生成的文件放在 `installer\dist\<版本>`。第三方组件适用各自的许可。 [第三方组件](THIRD_PARTY.md)
