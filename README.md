# 影音下载台

Windows 桌面影音浏览、下载和转码工具，从 amdl 升级而来。Apple Music、B 站、QQ 音乐、网易云音乐和 YouTube 使用同一个下载队列和 FFmpeg。

## 使用

1. 运行 `MediaDownloadDesk-Setup.exe`，或双击便携目录里的 `amdl.exe`。标准安装包已包含运行时、下载引擎、FFmpeg 和登录组件，并支持从 amdl 覆盖升级。
2. 在「音乐」搜索歌曲、艺人、专辑或歌单，或浏览当前地区的热门内容。搜索、热门、资料库和曲目列表会在接近底部时自动加载下一页，直到平台返回最后一页。双击歌曲可试听可用的短片段，双击专辑或歌单可展开曲目。点击列表表头可排序，整张歌单或专辑会按原始顺序拆成逐曲任务。
3. 点左下角「登录」，输入 Apple 账号和密码。Apple 要求双重认证时会弹出验证码窗口。输入的密码在登录过程中保持遮挡并留在表单里。Wrapper Lite 会在当前 Windows 用户目录中保存会话，amdl 默认在下次启动时恢复它。
4. 在「下载队列」选择音质和保存目录，再点「开始 / 继续」。也可以在这里添加 Apple Music 单曲、专辑或歌单链接。保存目录可选本地或外接磁盘。若填写分类，文件直接放在这一级分类内。
5. 在「设置」选择保留原音轨，或用 FFmpeg 转换成 FLAC、MP3、AAC、WAV、Opus。MP3 提供 128、192、256 和 320 kbps。

「资料库」可只读浏览个人歌曲、专辑和歌单。首次打开列表时会分批显示并保存完整的本地快照。下次先显示缓存，歌曲可立即排序或选择，Apple Music 在后台同步，成功后应用新增、修改和删除。同步失败时保留已有快照，点「刷新」可重试。已连接的 Apple Music 网页会话会自动加载。首次连接可在「资料库」填入自己的 Music User Token。个人上传曲目需要对应的 Apple Music 目录版本才能加入下载队列。

下载任务、结果和首次开始时选择的保存设置都保存在本机。重开程序后，点「开始 / 继续」处理剩余任务。已经完成的歌曲保留完成状态，Apple Music 中断的单曲从曲目开头重试。双击队列里的任务可查看保存路径和失败原因。要更换旧任务的目录或格式，选好新设置后右键任务，点「按当前设置重新排队」。

要制作车机歌单，在下载队列多选已完成的音频任务，右键选择「导出播放列表」。将 M3U8 保存在音乐文件所在的硬盘或 U 盘，并保持歌曲与歌单的相对位置。

## B 站视频

在左侧「B 站」粘贴视频链接、短链、BV 或 av 号，也可粘贴 UP 主合集、系列或公开收藏夹链接。点「查看分 P」可展开单条视频。直接从合集列表入队时，每条视频默认选择第一个分 P。队列支持 MP4、M4A、MP3 和平台实际返回的原始 FLAC。启用「自动分类」后，会按明确的标题标记分到 Persona 系列、音游、游戏原声、粤语或老歌。标记不足时沿用音乐或 B 站分区。所有分类都只建一层，手动指定的分类优先。保存音频时，会从标题识别歌名和演唱者，清理书名号和「纯享版」等修饰。投稿者与演唱者分别显示。

页面右上角可用哔哩哔哩 App 扫码登录，Windows 会加密保存会话。可用音轨和画质取决于 B 站实际返回，普通公开作品也支持游客下载。可勾选保存公开弹幕（ASS）和当前会话能读取的人工字幕（SRT）。中断后重新打开程序，点「开始 / 继续」。服务器验证原媒体仍一致时，自动从已确认的进度续传。源文件更新或服务器未提供可验证进度时，该分 P 从头开始，已完成的分 P 会跳过。

勾选「封面与资料」后，应用会在媒体文件旁保存公开封面和 JSON 作品资料。资料包括原始标题、分 P、歌手和投稿者。

音频识别有误时，右键曲目选择「编辑歌名和歌手」。标题中歌名和歌手的顺序颠倒时，可以点「互换」。加入队列后，应用会保存这次修正。

## QQ 音乐、网易云音乐、YouTube 和抖音

在「QQ 音乐」或「网易云音乐」输入歌名即可搜索，向下滚动会继续加载结果。也可粘贴公开单曲或歌单链接，查看曲目、打开原页面或导出 CSV。「网易云音乐」支持将平台返回的完整公开 MP3 直接下载或加入队列，保存音源并核验时长。

「QQ 音乐」和「网易云音乐」右上角可用对应手机应用扫码。登录后自动读取当前账号的歌单。打开歌单可选曲、下载或加入统一队列。下载时保存平台给当前会话返回的完整 MP3，具体曲目依照账号权限。登录会话由当前 Windows 用户加密保存。

「YouTube」可用关键词搜索视频，向下滚动加载结果。也可粘贴视频、Shorts 或公开播放列表链接。在页面或下载队列可选择 MP4 视频、M4A 音轨或 MP3，再开始下载。搜索和播放列表最多读取前 500 个结果位置。「抖音」支持通过默认浏览器打开视频、图文和短链。在抖音保存作品后，可点「导入已保存文件」进行转码或提取音频。

## 本地转码

把一个或多个本地影音文件拖到应用窗口，在鼠标旁选格式即可开始。也可以在「本地转码」先添加文件，再调整保存位置或格式。选项按所选文件类型提供，支持批量转换常见音频与视频，也能从视频提取音轨。转码使用随包 FFmpeg，默认保存到原文件旁边，可改为其他目录。原文件会保留。下载队列中的已保存文件可以右键送到「本地转码」。交互参考 [Filee](https://github.com/KnifeLemon/Filee)。

保留原音轨时只重新封装。FLAC 和 WAV 保留解码出的声道和采样精度。MP3、AAC 和 Opus 会把多声道音源混成立体声。有损源转换为 FLAC 后仍保留原有音质。应用根据曲目时长和实际编码检查每个下载文件，并检查输出可完整解码。重复内容会被识别，同名的不同文件会使用后缀保存。

## 组件

安装包带有 Python/Tk、apmyx 下载后端、FFmpeg、音频工具和 YouTube 下载组件。登录服务使用 [Wrapper Lite](https://github.com/itouakirai/wrapper)，由 amdl 按需启动。服务只监听本机回环接口。首次启动会校验并解压随安装包提供的官方组件，源码运行时也可从固定的官方发行版获取。音质档位受账户和歌曲实际供应影响。

账户页的「高级设置」可连接 Apple Music 网页会话。兼容模式的 ALAC 和 Atmos 可以使用已有的 `u22-amdl` 或在「组件」指定兼容服务。标准账号登录使用安装包自带的 Wrapper Lite。

## 本地构建

支持 Windows 10 2004 或更新版本，x64。源码可在装有 apmyx、Python 3.10+、Tk、PyYAML、Mutagen 及所需音频工具的机器运行。

```powershell
python -m pip install -r requirements.txt
python Studio.py
```

在原 AMDL 离线包中也可以用 `Run.cmd` 启动。需要构建安装包时，在 PowerShell 中运行下面的脚本。

```powershell
.\installer\Build.ps1
```

构建脚本会整理便携版和安装包，并校验 [Wrapper Lite v3.0.4](https://github.com/itouakirai/wrapper/releases/tag/v3.0.4) 后随包提供。也可用 `-WrapperLiteArchive` 指定本机已有的官方 ZIP。生成的文件放在 `installer\dist\<版本>`。第三方组件适用各自的许可。 [第三方组件](THIRD_PARTY.md)
