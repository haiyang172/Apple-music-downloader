# 影音下载台 · Windows 产品策划案

影音下载台（Media Download Desk）是从 amdl 扩展的 Windows 桌面应用，统一浏览 Apple Music、QQ 音乐、网易云音乐和 B 站内容。用户在同一个窗口连接账号、搜索或打开自己的歌单，选定输出格式和保存目录后交给下载队列。计划以一个 `MediaDownloadDesk-Setup.exe` 发布，支持从现有 amdl 升级。

## 一、产品功能

| 来源 | 浏览和选择 | 下载与保存 |
| --- | --- | --- |
| Apple Music | 保留歌曲、艺人、专辑和歌单搜索。授权后自动读取个人资料库和已收藏歌单，支持排序与多选 | 单曲、专辑和歌单逐曲排队。保留现有音质选项、原音轨及 FFmpeg 转码 |
| QQ 音乐、网易云音乐 | 扫码或浏览器授权后自动读取账号已创建和收藏的歌单。支持搜歌、粘贴单曲或歌单链接、多选歌单和曲目 | 下载前显示实际可用音质。可保留原始格式或转 MP3，并保存歌曲标签、封面和可用的 LRC 歌词 |
| B 站 | 识别普通链接、BV 号和短链，展开多 P 视频、合集、系列和收藏夹。登录后可浏览账号有权访问的内容，按分 P 勾选 | 保存 MP4 完整视频或仅音频。普通音轨可原样封装为 M4A，有原始 FLAC 时直接保存，另可转 MP3。可选保存字幕、ASS 弹幕、封面及元数据。支持批量、暂停、重试和断点续传 |
| 通用 | 下载前预览曲目、预计大小、来源音质、输出格式和目标路径 | 每条任务记住自己的输出设置。可恢复队列、筛选历史、重试失败项，并打开文件或所在目录 |

- **来源质量和保存格式分开选。** 例如「来源 AAC 256 kbps · 输出 MP3 320 kbps」，界面如实显示来源，避免把 MP3 输出码率或 FLAC 扩展名当成音质提升。音质自动降档时在结果中标明实际档位。只有试听或资源受账号、地区限制时，逐项说明并跳过。
- **媒体位置由用户选择。** 保存上次使用的可写目录，可选 H 盘或其他本地、外接磁盘。音乐默认直接放在所选目录，指定分类后只增加一级，例如 `H:\Music\音游\歌手 - 歌名.m4a`。同一歌单也可导出 M3U8，供车机播放列表使用。
- **账号按来源独立管理。** 左下角显示头像和登录状态。Apple 继续支持应用内账号、密码及独立验证码弹窗，失败或需要验证时保留当前表单输入。QQ、网易云和 B 站优先使用各自的扫码或浏览器授权。记住登录使用现有会话和 Windows 用户级凭据保护。退出一个平台只清除该平台会话。
- **授权成功后自动同步资料库。** QQ 音乐、网易云和 B 站按平台与账号缓存列表，再在后台刷新。切换账号时加载对应账号的资料库。Apple 当前的下载会话和资料库授权分别生效，账户界面集中展示两项状态。Apple 资料库授权从账户窗口打开应用内的官方网页，登录成功后自动验证并加密保存会话、显示个人资料库，之后启动时自动加载。

## 二、Windows 桌面界面

参考 Orchard 的应用结构。顶栏提供返回、前进和全局搜索；左栏放常用页面与来源；中间显示内容；账户固定在左下角，下载进度固定在底部。搜索默认针对当前来源，可切到全部已启用来源。点歌手、专辑或歌单进入详情，返回时恢复之前的搜索词、筛选、选中项和滚动位置。[Orchard](https://github.com/SFG5453/Orchard)

```text
┌─────────────────────────────────────────────────────────────────┐
│ 影音下载台 ‹  ›    搜索歌曲、艺人、专辑或粘贴链接     [来源 ▾]  │
├─────────────┬───────────────────────────────────────────────────┤
│ 搜索        │  歌单封面    Persona 系列                         │
│ 资料库      │              24 首 · Apple Music                  │
│ 下载        │              [下载所选]  [排序 ▾]                 │
│ 本地文件    │                                                   │
│             │  □  歌曲              艺人        专辑     时长   │
│ Apple Music │  □  曲目名称          …           …        03:21  │
│ QQ 音乐     │  □  曲目名称          …           …        04:15  │
│ 网易云音乐  │                                                   │
│ 哔哩哔哩    │                                                   │
│             │                                                   │
│ 设置        │                                                   │
│ 头像 · 账户 │  下载中 2 · 待下载 8               [查看任务]     │
└─────────────┴───────────────────────────────────────────────────┘
```

| 页面 | 核心交互 |
| --- | --- |
| 搜索与详情 | 搜索结果按歌曲、艺人、专辑、歌单或视频展示，跨来源结果显示平台。表格支持按标题、艺人、专辑或时长排序，保留歌单原始顺序选项。详情页提供封面、曲目表、批量选择及下载入口 |
| 资料库 | 已连接平台显示个人歌曲、专辑、歌单或收藏夹。支持按平台筛选、分页及刷新。未连接时直接提供当前平台的授权入口 |
| 下载确认 | 选择完整视频或仅音频、来源质量、输出格式、保存目录、分类和附件。预览文件名与预计大小，记住各平台上次使用的设置 |
| 下载中心 | 任务按歌单或合集分组，可展开到歌曲或分 P。显示 `第 3/24 首`、进度、速度和剩余时间。行内操作支持暂停、继续、取消、重试和打开文件 |
| 账户与设置 | 左下角打开账户面板，集中显示登录和资料库状态。常用设置保留目录、格式和并发数，组件和诊断放进高级设置 |

窗口标题、开始菜单和安装器统一显示「影音下载台」。应用图标使用多尺寸资源，界面图标使用清晰的矢量资源。浅色和深色都使用统一的强调色。卡片与弹窗用适度圆角，曲目表用平整的分隔线和清晰的选中态。英文和数字使用 Segoe UI，简体中文使用微软雅黑 UI。主界面优先显示名称、封面、状态和操作，技术说明放进提示或详情。紧凑窗口可折叠侧栏。验收覆盖 100%、125%、150%、200% 缩放、键盘焦点与长标题截断。

实现上建议用 **PySide6 / Qt Widgets** 做正式界面，继续调用现有 Python 下载和存储逻辑。先验证搜索表格、左下角账号弹窗及安装包在 Windows 高分屏下的表现，再迁移整套页面。Qt 运行库随安装包交付。[Qt for Python](https://doc.qt.io/qtforpython-6/) · [Qt 高 DPI 文档](https://doc.qt.io/qtforpython-6/overviews/qtdoc-highdpi.html)

## 三、统一下载队列

参考 TING-HiuYu 的逐曲拆分方式。一个歌单或合集生成一个批次，每首歌或每个分 P 对应独立任务，保留来源顺序及总数。上游 SQLite 只保存待运行项。影音下载台额外持久化运行状态、失败原因、输出文件和可用的续传检查点。[TING-HiuYu 项目设计](https://github.com/TING-HiuYu/apple-music-downloader#design)

1. **入队。** 完成分页解析后，一次写入批次和任务。每条任务保存平台、媒体 ID、歌单位置、格式、目标路径及目标磁盘标识。同一媒体从不同歌单入队时可以显示各自的位置，同时按输出目标处理重复文件。
2. **运行。** 下载、合并或转码、校验、发布分别报告进度。按平台和磁盘限制并发。源文件和附件完成校验后再写入最终路径，重名默认保留原有文件。
3. **恢复。** 重启时检查中断任务与已有输出。支持续传的下载从已验证的字节位置继续，远端资源变化或后端无法续传时只重跑该项。任务历史和已完成文件仍可查看。重启后恢复原来手动暂停的状态。
4. **等待与失败。** 外接盘拔出时等待原磁盘挂回，登录过期时显示「等待重新登录」，网络错误使用有限重试，权限和格式错误显示逐项原因。可批量重试选中项，批次汇总成功、跳过和失败数。

## 四、整合方式和发布

- **应用层**管理导航、账号、任务和设置。各来源适配器负责它自己的登录状态、搜索、资料库分页、链接解析和可用媒体规格。Apple 先封装现有 `engine.py`、`music_catalog.py`、`music_library.py`，用现有版本对照搜索、资料库和下载回归。
- **文件处理**复用现有 `storage.py` 的文件名、分类、磁盘和安全落盘规则，并扩展视频和附件。`audio.py` 当前按 Apple 音轨处理，新来源增加通用音频检查和标签写入。视频走独立的音视频合并、字幕和弹幕管线，共用安装包内的 FFmpeg，按实际校验需求打包 `ffprobe`。
- **安装和升级**延续 Inno Setup 和现有安装标识，集成 Python、界面运行库、媒体工具和所需平台组件。组件按需启动，安装器负责更新快捷方式和显示名称。升级保留设置、已有队列、登录会话和输出位置，数据库升级前生成备份。干净 Windows 10/11 x64 测试机器上用标准用户运行安装、启动、升级和卸载测试。
- **开源与依赖**在现有 GitHub 仓库发布源码和安装包，记录构建步骤、组件版本及 SHA-256。BiliFlow 和 MusicUnlock 的源码采用 MIT 许可，复用代码保留版权和许可声明。沿用 `THIRD_PARTY.md` 记录实际分发的 FFmpeg、Qt、登录组件及其他依赖的许可和构建来源。[BiliFlow 许可](https://github.com/itsVicOC/bilibili-downloader/blob/main/LICENSE) · [MusicUnlock 许可](https://github.com/Lin-M11/MusicUnlock/blob/main/LICENSE) · [FFmpeg 许可说明](https://ffmpeg.org/legal.html)

## 五、开发阶段与验收

| 阶段 | 交付内容 | 验收 |
| --- | --- | --- |
| 1. 桌面框架与任务基础 | 新界面、账户面板、Apple 接入、SQLite 队列和设置迁移 | Apple 歌单展开为逐曲任务，显示每首位置。下载中关闭或结束进程再打开，队列和历史可恢复。已完成的歌曲不会重下 |
| 2. B 站 | 链接解析、多 P、合集与收藏夹、视频和音频输出、附件 | 同一合集分别导出 MP4 与仅音频。核对 M4A、实际提供的 FLAC、ASS/SRT 文件。断网和重启后验证支持任务的续传 |
| 3. QQ 音乐与网易云 | 授权、自动读取资料库、搜索、歌单多选、批量下载 | 两个平台登录后均可多选个人歌单。用有权限的曲目核验源格式、MP3、封面和标签。模拟会话过期、试听和不可用曲目，验证其他任务继续 |
| 4. 正式 Windows 发布 | 单安装包、升级迁移、中文界面和 GitHub 发布 | 新装与从 v0.3.2 升级均能启动。验证中文路径、用户自选盘符、H 盘拔插、单层分类、各档显示缩放和每个平台的完整下载流程 |
| 5. 上游扩展功能 | B 站直播监控和录制，歌单追更，本地音频批量转码、曲库整理、去重审阅、标签编辑与 M3U8/CSV 导出 | 直播断线后可继续录制并合并片段。追更只下载新增曲目。曲库清理可预览，标签批改可撤销 |

阶段 5 可继续扩展到 MusicUnlock 的其他平台及自动化能力，包括酷狗、酷我、目录监听、媒体库同步和命令行。BiliFlow 的直播录制与 MusicUnlock 的本地转换可沿用同一个任务中心，各自提供独立的媒体处理流程。[BiliFlow 用户指南](https://github.com/itsVicOC/bilibili-downloader/blob/main/docs/USER_GUIDE.md) · [MusicUnlock 功能清单](https://github.com/Lin-M11/MusicUnlock#功能特性)
